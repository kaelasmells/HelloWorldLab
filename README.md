### This is the LAB1 Readme.

When the app is first run, the text "Hello World!", a text editor bot saying "Enter your name," and a button that says "CLICK ME" are on the screen.
When the user writes their name in the "Enter your name" text editor, and clicks the "CLICK ME" button, the text "Hi, " appears, followed by the user's name, replacing the original "Hello World!" text.
